# 🚀 Featured Project

## 🏛️ KHEMET — AI Tourism Platform

**KHEMET** is an AI-powered tourism platform designed to create an interactive digital experience for exploring ancient Egyptian artifacts.

### ✨ Key Features

| Feature | Description |
|---|---|
| 📸 Artifact Recognition | AI-powered artifact identification |
| 🤖 AI Assistant | Interactive tourism assistant |
| 🔤 Hieroglyph Translator | Translate and understand hieroglyphs |
| 🔊 Voice Tour Guide | AI-powered voice experience |
| 🌍 Multilingual Support | Support for multiple languages |

### 🧠 AI Stack

```text
TensorFlow • CLIP • YOLO • Llama • Groq • ChromaDB • ElevenLabs
```

### ⚙️ Application Stack

```text
Flutter • Dart • Node.js • Express.js • PostgreSQL • REST APIs • JWT Authentication
```
